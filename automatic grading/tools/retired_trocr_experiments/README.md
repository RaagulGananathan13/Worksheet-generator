# Retired TrOCR experiments

These scripts evaluated the former TrOCR recognizer (removed in favour of GLM-OCR with a second-model cross-check). They call functions that no longer exist in `app/ocr.py` and are kept only as a record of the earlier diagnostics described in `docs/OCR-EVALUATION.md`. Use `tools/evaluate_handwriting.py` for the current engines.
